# Linux Privilege Escalation Automation Toolkit 🔐🐧

A Python-based automated security auditing toolkit designed to identify common Linux privilege escalation vectors, system weaknesses, and misconfigurations.

## 📌 Project Overview

Linux Privilege Escalation Automation Toolkit helps security researchers, penetration testers, and cybersecurity students analyze Linux systems by automating security checks that are commonly performed during privilege escalation assessments.

The toolkit scans for insecure permissions, dangerous binaries, weak configurations, and potential escalation opportunities.

## 🚀 Features

- 🔎 System information enumeration
- 🔑 SUID/SGID binary discovery
- 📂 Weak file permission detection
- 🛡️ Sudo privilege misconfiguration checks
- ⚙️ Enabled service auditing
- ⏰ Cron job vulnerability checks
- 🐧 Kernel version security assessment
- 📊 Severity-based vulnerability reporting
- ✅ Security hardening recommendations

## 🛠️ Technologies Used

- Python 3
- Linux Shell Commands
- Linux Security Concepts
- Privilege Escalation Techniques
